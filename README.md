# Calculadora em Python
Projeto acadêmico desenvolvido em Python que implementa uma calculadora interativa pelo terminal.

## Tecnologias utilizadas
Python 3
Biblioteca padrão math

## Como instalar e executar
O projeto não utiliza bibliotecas externas, portanto não é necessário instalar dependências adicionais.
Certifique-se de ter o Python 3 instalado e execute o arquivo do projeto pelo terminal.

## Funcionalidades
Após iniciar o programa, é possível escolher entre as seguintes opções:

1- Operações básicas — soma, subtração, multiplicação e divisão.

2- Cálculo de média — média aritmética ou ponderada.

3- Equação — resolução de equações de 1º e 2º grau.

4- Fatorial — cálculo do fatorial de um número.

5- Conversão de unidades — conversão de metros para quilômetros, decímetros, centímetros ou milímetros.

6- Tabuada — exibição da tabuada de um número de 1 a 10.

7- Fibonacci — geração dos primeiros 10 valores da sequência.

## Exemplo de uso
Ao executar o programa, o usuário **seleciona a opção da calculadora desejada**. Por exemplo, para calcular uma soma:

[1] - Operações básicas
[2] - Cálculo de média
[3] - Equação
[4] - Fatorial
[5] - Conversão de Unidades
[6] - Tabuada
[7] - fibonacci

**Escolha uma calculadora**: 1

Insira um valor: 10

**Escolha a operação**:
[+] - Soma
[-] - Subtração
[*] - Multiplicação
[/] - Divisão
[=] - Fim: +

**Insira outro valor**: 5

**Escolha a operação**:
[+] - Soma
[-] - Subtração
[*] - Multiplicação
[/] - Divisão
[=] - Fim: =

Reultado: 15.0

O programa funciona por meio de menus interativos, recebendo os valores digitados pelo usuário e exibindo os resultados diretamente no terminal.
